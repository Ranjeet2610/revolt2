# 🚀 Revolt Bot - Quick Start Guide

## Single Command Setup & Run

**Just run this ONE command to get everything working:**

```bash
./run.sh your_username
```

### Examples:
```bash
./run.sh mybot
./run.sh testuser
./run.sh revolthandler
```

## What the Script Does Automatically:

✅ **Installs Node.js** (if not installed)  
✅ **Installs Chromium** (if not installed)  
✅ **Installs npm dependencies** (if not installed)  
✅ **Starts the Revolt Bot** with your username  
✅ **Opens Chromium browser** for Revolt login  
✅ **Shows web dashboard** at http://localhost:PORT  

## Requirements:

- **Ubuntu/Linux** system
- **Internet connection** (for downloading dependencies)
- **sudo access** (for installing system packages)

## That's It! 

The script handles everything automatically. After running the command:

1. **Chromium will open** showing Revolt login page
2. **Login to your Revolt account**
3. **Web dashboard opens** for bot configuration
4. **Start using your bot!**

## Stop the Application:
Press `Ctrl+C` to stop the bot

## Troubleshooting:

If something goes wrong, the script will show you exactly what's missing and try to fix it automatically.
